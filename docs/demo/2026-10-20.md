# Демонстраційний випуск за 20 жовтня 2026 (реальні відкриті новини)

**Статус: ТЕХНІЧНИЙ ТЕСТ. Не затверджено редакцією, не опубліковано.**
Для перевірки повного ланцюжка «затвердження» виконано в тимчасовій копії репозиторію від імені `DEMO-test` з автоматичним позначенням 8 чутливих речень як перевірених. У репозиторії лежить лише чернетка (`editions/2026-10-20/draft.json`, `draft.md`) — вона чекає справжнього редактора. Аудіо в репозиторій не додано.

## Що містить випуск

- **Сценарій і посилання на джерела:** [`editions/2026-10-20/draft.md`](../../editions/2026-10-20/draft.md) — 21 сюжет: 7 національних, 5 в огляді регіонів, по 3 для Волині, Хмельниччини й Закарпаття; під кожним — усі матеріали кластера з URL.
- **Журнал перевірки фактів:** `draft.json` → для кожного речення `claims[]` (число/ім'я/цитата/дата → `found_in` ID матеріалів → URL у `sources[]`), `status`, `reasons`. Підсумок: 68 речень, 60 ✓, 8 ⚠ (загиблі/поранені з одного джерела або минулі роки), 0 ✗.
- **Журнал відбору:** `draft.json → log`: виключені матеріали (15: реклама, колонки, промо), пропущені кластери (11 можливих дублів уже відібраних сюжетів), 40 найвищих кандидатів з оцінками.

## Помічені обмеження

- Piper: помилки в прізвищах і абревіатурах, неприродна інтонація — для публічного випуску потрібне прослуховування й, імовірно, комерційний голос (див. `docs/TTS.md`).
- Екстрактивний текст звучить як стрічка заголовків; окремі речення анотацій довгі (до ~45 слів) — редактор може скоротити на сторінці перевірки.
- Кластеризація свідомо обережна: частина повідомлень про ту саму подію лишається окремими кластерами; повтори в ефір не потрапляють завдяки другому запобіжнику, але кількість «незалежних джерел» для таких подій занижена.
