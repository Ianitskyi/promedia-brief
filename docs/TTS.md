# Вибір TTS для української мови

Методика: однаковий тестовий сценарій `docs/tts/test-script.txt` (імена, топоніми, числа, дати, абревіатури, цитата) озвучується кожним кандидатом командою

```bash
python scripts/tts_compare.py --providers piper google azure openai elevenlabs --out /tmp/tts-compare
```

або в GitHub: Actions → **Compare TTS voices** (нічого не комітить; mp3 і таблиця — в артефакті та підсумку запуску; платні сервіси — лише з позначкою погодження бюджету).

Для кожного: час рендеру, символи, оцінка вартості, **CER ASR-зворотного перекладу** (аудіо → faster-whisper → порівняння з текстом) як об'єктивний показник точності читання, і mp3 для **сліпого прослуховування** редакцією (природність, наголоси, прізвища, темп). Маркетингові описи не враховуються.

## Рішення (21.10.2026)

Щоденний випуск озвучує **StyleTTS2, голос male_2** (`config/editorial.json` → `edition.tts_provider`, `tts_voice`). Причина: Piper звучав штучно і повільно (≈115 слів/хв). Piper лишається резервом.

**Відкрите питання:** стилі голосів у моделі підписані іменами реальних людей, а походження навчальних записів у картці моделі не описано. Перед комерційним запуском варто отримати від автора моделі підтвердження, що диктори погодилися на таке використання, або перейти на голос із явною згодою (власний диктор чи комерційний TTS).

## Рекомендація щодо платних сервісів

1. Погодити витрату ≈ $0.15 і надати ключі (як GitHub secrets) для Google і Azure — обидва в межах безкоштовних квот покривають пілот.
2. Прогнати `tts_compare.py`, провести сліпе прослуховування 2–3 редакторами.
3. Piper залишити як безкоштовний резерв і для технічних прогонів; для публічного випуску його якість, імовірно, недостатня (рішення — за редакцією після прослуховування).

## Демо-випуск платним голосом

Actions → **Demo edition (paid voice)** озвучує вже затверджений випуск платним сервісом (ElevenLabs за замовчуванням, модель `eleven_v3` з тегами тону з `config/editorial.json` → `tts_moods`) і зберігає його в `demo/` — ця тека не видаляється через 7 днів. Сторінка: `/demo.html` (плеєр, текст, джерела кожного сюжету, результат звірки аудіо з текстом). Щоденний випуск на сайті не змінюється.

Потрібно: secret `ELEVENLABS_API_KEY`; змінні репозиторію `ELEVENLABS_VOICE_ID` (голос новин) і, за бажання, `ELEVENLABS_SERVICE_VOICE_ID` (вступ, нагадування, завершення). Список голосів, доступних ключу, — у підсумку запуску. Витрати не почнуться без позначки «I approve spending…»; запобіжник `BRIEF_MAX_TTS_USD` (типово $1.00). Один випуск ≈ 5–6 тис. символів ≈ 5–6 тис. кредитів ElevenLabs.

## Наголоси

A/B-тест 22.10.2026 (ElevenLabs v3): з позначками наголосу за словником `ukrainian-word-stress` наголоси правильніші, ніж без них, тож демо озвучується з позначками (`BRIEF_ELEVENLABS_STRESS=1`, вхід `stress` демо-workflow). Помилки словника (напр. «підлі́тків» замість «пі́длітків») виправляються в `config/stress.json`.


Наголоси для StyleTTS2 ставить `ukrainian-word-stress`; іноземні імена він часто наголошує неправильно («Дона́льд», «Вітко́фф»). Виправлення — у `config/stress.json` (`+` після наголошеної голосної; `prefix: true` — і для відмінкових форм). Ці позначки додаються лише до тексту для рушія, затверджений текст не змінюється.

## Гарантії точності

- TTS отримує лише затверджений текст (sha256 перевіряється перед рендером і публікацією).
- Кожне речення озвучується окремо; довгі ріжуться за межами речень/фраз; `chunk_text` перевіряє, що нічого не втрачено, не повторено й не переставлено.
- Словник вимови (`config/lexicon.json`) змінює лише звучання; він — чернетка до прослуховування.
- `brief verify-audio` порівнює аудіо з текстом; сегмент з CER > 20 % блокує публікацію (короткі заголовки не оцінюються).
