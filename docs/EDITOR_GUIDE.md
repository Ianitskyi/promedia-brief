# Інструкція редактора BRIEF

1. Щодня близько 18:40 за Києвом (узимку — 17:40) workflow **Draft BRIEF edition** готує чернетку (або запустіть його вручну в Actions).
2. Відкрийте `https://brief.promedia.report/review.html` (сторінка не індексується пошуковиками, але доступна за посиланням).
3. Для кожного сюжету:
   - **✓ підтверджено** — кожне число, ім'я, цитату й дату знайдено в матеріалах джерел (посилання поруч);
   - **⚠ потребує підтвердження** — загиблі/поранені/бойові дії лише з одного видання або згадка минулих років. Відкрийте першоджерело і лише тоді позначте «перевірено за першоджерелом»;
   - **✗ не підтверджено** — блокує затвердження; виправте або виключіть сюжет.
   - Можна скоротити чи переписати речення. Нове число, ім'я або цитата, яких немає в джерелах сюжету, заблокують затвердження.
   - Сюжети «обов'язковий» (головні новини дня) не можна тихо виключити.
4. «Завантажити змінений draft.json» → GitHub → `editions/<дата>/` → Add file → Upload files → Commit.
5. Actions → **Approve and render BRIEF edition**: дата, sha256 зі сторінки, постачальник TTS (платний — лише з позначкою погодженого бюджету). Workflow повторно перевіряє текст, записує вас як затверджувача, озвучує, звіряє аудіо з текстом і публікує. За будь-якої невідповідності нічого не публікується.

Перевірки автоматичні й не є гарантією: вони не помічають, якщо скорочення змінило зміст речення. Відповідальність за випуск — на редакторі.
