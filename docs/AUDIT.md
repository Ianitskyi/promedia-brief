## Додаткові спостереження

- `robots.txt` 50 регіональних сайтів містить `content-signal: ai-input=no`. Поточний конвеєр не використовує ШІ для обробки текстів, але сигнал зберігається в реєстрі та в кожному матеріалі (`content_signals`), щоб будь-який майбутній ШІ-етап міг їх виключити.
- Звукові заставки (`audio/intro.mp3`, `bumper.mp3`, `outro.mp3`): походження й права в репозиторії не задокументовані — потрібне підтвердження.
- Сирі пули `data/raw/*.json` і чернетки лежать у **публічному** репозиторії та на GitHub Pages (заголовки й анотації джерел).
