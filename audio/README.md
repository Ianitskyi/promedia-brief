# BRIEF sonic identity

The product should use one recognisable sound motif, not three unrelated jingles.

## 1. Intro sting
Length: 2–3 seconds.

Structure:
- same 4–5 note BRIEF sonic motif
- clean, modern, restrained
- spoken line: **«BRIEF by ProMedia»**

## 2. Mid-roll bumper
Length: 1–1.5 seconds.

Structure:
- shortened version of the same motif
- spoken line: **«Ви слухаєте BRIEF»**

Use once in a roughly 8–12 minute episode, around the natural midpoint. Do not interrupt a sentence or story.

## 3. Outro
Length: 2–3 seconds.

Structure:
- resolved version of the same motif
- optional spoken line: **«Це був BRIEF by ProMedia»**

## Sound direction
- contemporary news / public-radio feel
- calm, intelligent, recognisable
- no cinematic drama
- no alarm-like sounds
- no generic corporate ukulele
- no imitation of an existing broadcaster
- subtle plucked-string texture is acceptable, but avoid folk cliché
- motif must remain clear on phone speakers

## Music-AI generation brief
Generate a very short instrumental sonic logo for a modern Ukrainian audio-news product called BRIEF. Create one memorable 4–5 note motif with clean electronic percussion, a restrained plucked-string texture, and a warm modern synth layer. Calm, intelligent, trustworthy, contemporary, not cinematic, not corporate, not playful. Designed for spoken-news transitions and phone speakers. No vocals. No resemblance to any existing broadcaster or podcast theme.

Generate several variations of the same motif, then edit one master motif into:
- intro.wav
- bumper.wav
- outro.wav

## Voice
The same Ukrainian voice used for the main briefing should speak the brand lines, so the sonic identity stays coherent.
