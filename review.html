ЧЕРНЕТКА — не для поширення. Автоматичні перевірки шукають у джерелах кожне число, ім'я, цитату й дату, але не гарантують достовірність. Відповідальність за випуск — на редакторі.

Як затвердити випуск
  1. Відредагуйте речення, вимкніть зайві сюжети, підтвердіть позначені «⚠» речення (лише після перевірки за посиланнями).
  2. Натисніть «Завантажити змінений draft.json» і завантажте файл у репозиторій як editions/DATE/draft.json (GitHub → Add file → Upload files → Commit).
  3. Запустіть GitHub Actions → Approve and render BRIEF edition з датою та sha256, показаним угорі. Затвердження повторно перевіряє текст; якщо він змінився або є непідтверджені речення — нічого не буде озвучено.

Змінені речення позначаються «змінено»: їх буде перевірено повторно під час затвердження. Будь-яке нове число, ім'я чи цитата, яких немає в джерелах сюжету, заблокує затвердження.
